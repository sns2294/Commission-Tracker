# Commission Tracker

A simple earnings tracker built for commission-based pay — log entries by date and amount, track totals by pay period, and keep a running all-time total.

## Features
- Add, edit, and delete earnings entries (date + amount)
- Choice of pay period to track against
- Pay-period total and all-time total, calculated automatically
- Entry count and history, grouped by pay period
- Clean, minimal dark-mode interface

## Tech
Built as a single `index.html` file — HTML, CSS, and JavaScript, no frameworks or dependencies. Runs entirely in the browser.

## Why I built it
I'm fully commission-based at my job and wanted a simple day-to-day way to track earnings without spreadsheets or a clunky app. Built with [Claude Code](https://www.anthropic.com/claude-code) as a hands-on way to learn AI-assisted development.

## Usage
Clone or download the repo and open `index.html` in your browser, or visit the live version via GitHub Pages.
